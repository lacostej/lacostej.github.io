CoffeeBreaks started as the name of my first consulting company. For a while it
was also a blog, on a domain I no longer own. This is the blog part, restarted —
a Hugo site published straight from GitHub Pages.

I expect to write about a few things.

Small projects I build for the fun of it, like the Samsung AirTag tracker I'm
currently poking at.

The software behind running the businesses — the order management system, the
daily zero reconciliation, migrating the flower shop to Shopify.

And the business itself: the KPIs we actually look at, how we ended up
structuring information the way we did, what we monitor and why. This last one is
the category I never see written about honestly, so it's probably where I'll
spend most of my time.

More soon.
